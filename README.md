# 🧫 Visualizador de Medios de Cultivo (Microbiología)

Visualizador interactivo y espacial de medios de cultivo microbiológicos, con diseño minimalista estilo Apple, vista de lienzo espacial libre (pan & zoom) y vista de tabla comparativa.
